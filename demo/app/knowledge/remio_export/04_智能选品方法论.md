# 智能选品方法论

## 选品核心维度
- **市场需求**：目标市场体量、增长速率、季节性；
- **竞争程度**：红海/蓝海判断，头部集中度；
- **利润空间**：采购成本、物流、认证、平台费用、税费后的净利；
- **供应链稳定**：义乌国际商贸城 7.5 万商户、210 万+ SKU 的供给保障；
- **合规门槛**：认证与清关难度是否可控。

## 蓝海选品策略
1. 借助"义乌指数"识别上涨品类与新兴趋势；
2. 避开同质化严重的标品，寻找差异化微创新点；
3. 组合"高复购 + 低售后 + 轻小件"降低履约风险；
4. 用工具（如竞品实采 Agent）在 Amazon/1688 真实调研价格带与差评痛点，反推机会点。

## 利润测算模板
- 采购成本 + 物流费用 + 认证费用 + 平台费用 + 运营费用 = 总成本；
- 预计月销量 × 客单价 − 总成本 = 预计月利润；
- 盈亏平衡销量 = 固定成本 / 单件毛利；
- 建议 ROI 目标 ≥ 20%。

## 行动节奏（3 阶段）
- 阶段1 市场调研与选品：需求/竞品/认证/供应商报价；
- 阶段2 样品测试与认证：品质测试、认证申请、1039 备案、物流方案；
- 阶段3 首批采购与发货：下单、义新欧/海运、清关文件、上架 listing。
