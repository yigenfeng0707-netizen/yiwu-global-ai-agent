# 官方六维评审标准对标自评表

> **用途**：本表以 **2026"直通乌镇"全球互联网大赛 · OPC 特色赛官方评审标准**为唯一对标口径，替代《升级改造方案 V2》中项目自建的"七维"代理评分。凡涉及参赛策略、路演重点、答辩准备，一律以本表为准。
> **编制**：2026-09-11 ｜ **数据来源**：官方复赛公开报道（见文末来源）+ 项目代码/文档实测核验
> **一句话结论**：项目在官方**第一维度"AI 工具的应用能力"上是全场级强项**（8.5–9），真正卡住争冠的是**"核心竞争力"（数据护城河大部分仍是演示）**和**"团队能力/可复制性"缺 0 真实商户证据**——这两项无法靠改文档解决，需创始人外部推进。

---

## 0. 官方要求速览（经核实）

| 项 | 官方口径 |
|---|---|
| 赛事全称 | 2026"直通乌镇"全球互联网大赛 · **OPC 特色赛**（One Person Company / 一人公司 / 超级个体） |
| **评审标准（六维综合评审）** | ①**AI 工具的应用能力** ②**原创性** ③**核心竞争力** ④**可复制性** ⑤**团队能力** ⑥**未来发展潜力** |
| **评委构成** | **技术界、学术界、投资界**专家（⚠️ 无"产业界"——V2 曾误设产业界/学研界，已在《答辩QA手册》速查表更正） |
| 赛制 | 网络初赛筛选 → 各城市复赛 → 世界互联网大会乌镇峰会期间**总决赛** |
| 复赛组别 | **数字商业运营 / 数字服务赋能 / 数字内容创新** 三大组别 |
| OPC 定义 | 借助 AI 工具与平台，以**极简团队或一人公司**形式实现产品、服务与商业模式突破；强调 **AI 原生应用** |
| 参赛对象 | 高校师生创业团队、初创公司、个人创业者 |

> ⚠️ **关键错位提醒**：V2 自建七维中的"政策契合度（9.5 满分）"在官方六维里**不是独立计分维度**，只能间接喂给"原创性"和"未来发展潜力"。项目此前把大量精力投在政策叙事上，属于**在非计分维度过度投资**；而官方权重最高的"AI 工具应用能力"恰是项目最强项，应作为路演与答辩的**开场主线**（已在 5 分钟版路演稿落地"AI 先行"）。

## 1. 官方六维对标评分（当前状态，含 P4 批次改造后）

| 官方维度 | 当前自评 | 目标 | 核心依据（已核验） | 主要差距 |
|---|---|---|---|---|
| **①AI 工具的应用能力** | **8.5–9.0** | 9.0 | 7 个 Agent 全部 LLM 增强（原 4 个"哑"Agent 已接入，各含 8–10 处 LLM 调用）；真 LangGraph StateGraph 编排（7 节点+条件边，非顺序包装）；DashScope qwen-plus + 备选降级 + 半开熔断 + 每日限额落盘；无 key 优雅降级 ai_used=false；CI 四门禁 196 测试全绿 | 已接近天花板，靠现场演示"眼见为实"守住 |
| **②原创性** | 7.5–8.0 | 8.5 | "义乌经验 + 7 AI 数字员工 + 1039 模式 + 39 城复制"领域组合原创；供应链匹配 Agent（直连义乌 7.5 万商铺）、政策复制 Agent（经验编码为可迁移 SOP）无直接竞品 | 技术底座（LangGraph/LLM）通用，原创在领域应用而非底层技术 |
| **③核心竞争力** | **6.5–7.0** | 8.5 | 2 个真实数据源（汇率 open.er-api.com + 义乌指数 ywindex.com 官方发布值）可现场自证；义新欧线路已建 ETL 管道（快照降级态） | ⚠️ **最大短板**：7.5 万商铺 / 210 万 SKU 仍是**静态演示数据**；数据护城河未真正建成；义乌商贸城数据合作无正式协议（P4-1 LOI 待签） |
| **④可复制性** | 7.5–8.0 | 8.5 | 39 城复制 + 政策复制 Agent + 城市合伙人分润模型，叙事与方法论完整 | **无真实复制证据**：0 真实商户、0 已复制城市落地案例（P4-4 待推进） |
| **⑤团队能力** | 6.5–7.0 | 8.0 | 契合 OPC"一人公司"本意（1 创始人 + 7 AI 数字员工）；创始人冯亦根技术+跨境双背景、浙江省首批产业教授、**创梦杯 OPC 三等奖**背书；Q15 已备"一人如何持续迭代"答辩 | 投资界会担心执行深度与持续性；兼职协作口径需与"超级个体"叙事统一 |
| **⑥未来发展潜力** | 8.0–8.5 | 9.0 | 三级增长飞轮（义乌→39 城→全国县域）；B2G 政府采购（39 城×50 万/年）+ B2B 城市合伙人双轮；财务模型 P4-7/8 后可信度提升（LTV/CAC=24:1 可推导、净利率诚实分阶段） | 潜力依赖营收预测兑现，而预测又依赖③④的真实落地 |

**综合（官方六维口径）≈ 7.5–8.0 / 10**：**稳过复赛线，离争冠差两块硬证据（③数据真实性、④/⑤真实商户）。**

## 3. 争冠级差距与行动清单

### 3.1 只有创始人能做的（决定③④⑤能否从 6.5 冲到 8+）

| 行动 | 对应官方维度 | 预期拉动 |
|---|---|---|
| **P4-1** 争取《义乌中国小商品城集团数据合作意向书（LOI）》签署（哪怕初步意向/沟通记录） | ③核心竞争力 | +0.5，把"数据护城河"从演示变可信 |
| **P4-4** 争取 1–2 个真实义乌商户使用证据（微信反馈截图/真实注册记录/店铺照片） | ④可复制性、⑤团队 | +0.8，从"0 真实商户"到"有真实证据"的质变 |
| **P4-5** 把 P4-4 真实证据补进《商户内测报告》 | ④可复制性 | +0.4（依赖 P4-4） |
| **P4-12** 联系嘉兴/义乌 OPC 社区申请入驻（拿受理号） | ⑥潜力、⑤团队 | +0.2，把政策契合从叙事变事实 |

### 3.2 我可继续独立做的（守住①、补强②⑥）

- **P4-2 收尾**：把义乌指数"趋势分析 → Agent 自动解读什么品类在涨 → 选品联动 → 前端真实时间戳图表"做成完整可现场点击的闭环，进一步坐实①和③。
- **组别定位物料**：确认报名组别（见 §4），并针对该组别评委偏好微调路演侧重。
- **技术界答辩弹药**：整理 LangGraph 架构图、7 Agent LLM 增强证据、CI 四门禁截图，供技术界评委现场核验。

## 4. 复赛组别建议

| 组别 | 是否契合 | 理由 |
|---|---|---|
| **数字商业运营** | ⭐ **首选** | OPC 本质是帮义乌商户做跨境**商业运营**（选品/定价/合规/供应链/营销），是典型的数字商业运营 AI 应用 |
| **数字服务赋能** | ✅ 备选 | 若强调"为 210 万中小微企业/39 城提供出海**服务赋能**、B2G 政府采购公共服务"，可归此组 |
| 数字内容创新 | ❌ 不契合 | 项目非内容创作类产品 |

> **建议**：报名**数字商业运营**组（与"AI 原生 + 商业运营突破"的 OPC 定义最贴合）；若该组竞争激烈，可用"数字服务赋能"角度差异化（突出 39 城公共服务 + 政府采购）。**最终组别请以组委会报名系统可选项为准。**

## 5. 一句话总评

**这个项目在官方最看重的"AI 工具应用能力"上已经足够强、且可现场自证；它不缺工程量、不缺叙事、不缺政策高度，缺的是"数据是真的"和"商户是真的"这两块能拿出手的证据。** 把 P4-1（数据合作 LOI）和 P4-4（真实商户）做成，③④⑤三维可从 6.5–7 抬到 8+，综合分即可从 7.5–8.0 冲进 8.5+ 争冠区间。
