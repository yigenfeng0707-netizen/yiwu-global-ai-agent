2. **初赛提交**：个人中心 →「参赛项目」按需上传 **方案文档、作品、Demo、演示视频**。
3. **复赛提交**（若入围）：辅导优化后于 09-20 前再次提交。
4. **决赛**：10-16 现场答辩（5+3 或更长），提交路演素材。
