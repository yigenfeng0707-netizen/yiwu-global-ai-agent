# 演示视频录屏指南（金漪湖·论剑 OPC 智能体赛道）

> 目的：给评委一段可复现的 Demo 视频脚本。全程在 remio 桌面端（国区 remiocn）内操作，证明"官方工具 + 智能体能力 + 工具调用与自主性"。

## 录屏环境准备
1. 安装并登录 remio 国区桌面端（remiocn），确保「aApps / 应用市场」可用。
2. 安装本作品 aApp「义乌小商品出海助手」v3（搜索 aApp ID `yiwu-opc-assistant`，或从市场包 `…/yiwu-opc-assistant-v3.zip` 安装）。
3. 知识库已含集合「义乌跨境 OPC 知识库」（5 篇：1039 政策 / RCEP 关税 / 跨境合规 / 智能选品 / 金义新区落地）。
4. 联网（竞品实采需访问 Amazon / AliExpress / 1688）。

## 分镜脚本（建议 3–5 分钟）

| # | 画面 | 旁白要点 | 期待结果 |
|---|------|----------|----------|
| 1 | 打开 remio → aApps → 义乌小商品出海助手 | 介绍作品定位：义乌小商品出海智能体，基于 remio 官方工具 | 展示 aApp 入口与欢迎语（v2/v3 能力说明） |
| 2 | 点击菜单「1039 市场采购怎么免税？」 | 展示"官方工具建知识库 + RAG 带引用" | 流式回答，含笔记引用来源 |
| 3 | 输入框：「请竞品实采：无线耳机」 | **核心**：智能体自主调用无头浏览器抓取真实电商页 | 进度条显示 `headless_fetch_content` 抓取 Amazon/AliExpress/1688；返回各页正文片段 |
| 4 | 同上结果续 | 展示 LLM 提炼的竞品洞察：价格区间/卖点/差异化/选品建议 | 结构化洞察输出，证明"工具调用与自主性" |
| 5 | 菜单「智能选品推荐」「跨境合规检查」「政策复制与金义新区落地」 | 展示多端点编排（选品/合规/政策复制） | 三个端点分别基于知识库给出专业回答 |
| 6 | 收尾字幕 | 强调：获奖后注册落地金义新区、入驻 OPC 社区、向 39 城复制 | 赛道契合度与落地承诺 |

## 备选（后端全链路，给技术评委）
- 本地 `docker compose up` 启动 FastAPI 后端，调用 `/api/v1/competitor-research`、`/api/v1/market-insight` 等，展示 7 大 Agent 与外部浏览器自主操作（见仓库 `demo/` 与 `Dockerfile`）。

## 录制建议
- 用 OBS / 系统录屏，分辨率 1920×1080，开启鼠标高亮。
- 第 3 步务必等真实抓取进度出现再讲解，这是评分关键帧。
- 视频命名：`义乌小商品出海智能体-OPC_Demo.mp4`，连同本指南、市场包链接、GitHub 仓库一并提交。
